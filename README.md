# PhonePe Transaction Insights

PhonePe Pulse data analysis with SQL, Python & Streamlit dashboard.

## Setup
1. `pip install -r requirements.txt`
2. MySQL: Run `sql/create_database.sql`
3. `git clone https://github.com/PhonePe/pulse.git data`
4. `python sql/load_data.py`
5. `streamlit run streamlit/app.py`

## Database
MySQL: phonepe_pulse (8 tables)
